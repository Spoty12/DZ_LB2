#                   **Домашнее задание к работе 2**

## Условие задачи

Человеку нужно съездить из Лондона в расположенный в 390 милях Эдинбург. Он
может ехать на авто-мобиле марки “Роллс-Ройс” либо на автомобиле марки “Форд Эскорт”. “Роллс-Ройс” расходует 1 галлон бензина на каждые 15 миль пути. “Форд-
Эскорт” расходует 1 галлон бензина на каждые 36 миль пути. Сколько будет стоить по-
ездка в Эдинбург на “Роллс-Ройсе”, если стоимость 1 галлона бензина составляет х
фунтов? Сколько денег он сбережет, если вместо этого поедет на машине марки
“Форд-Эскорт”. 

## Алгоритм

1. Начало

2. Объявить константы:
- `distance = 390` — расстояние от Лондона до Эдинбурга (миль).
- `rolls_royce_mpg = 15` — количество миль на 1 галлоне бензина для Rolls-Royce.
- `ford_escort_mpg = 36` — количество миль на 1 галлоне бензина для Ford Escort.
3. Задать исходные данные:
- `x` — стоимость 1 галлона бензина (фунтов).
4. Найти количество бензина для каждой машины:
- `fuel_rolls_royce = distance / rolls_royce_mpg`
- `fuel_ford_escort = distance / ford_escort_mpg`
5. Рассчитать стоимость поездки на каждой машине:
- `cost_rolls_royce = fuel_rolls_royce * x`
- `cost_ford_escort = fuel_ford_escort * x`
6. Рассчитать экономию при поездке на Ford Escort:
- `savings = cost_rolls_royce - cost_ford_escort`
7. Вывести результаты расчётов с подстановкой всех значений в текст:
- стоимость поездки на Rolls-Royce;
- стоимость поездки на Ford Escort;
- сумма экономии в фунтах.
8. Конец
## Блок-схема алгоритма

``` mermaid
flowchart TD
    A([Начало]) --> B[/Ввести стоимость бензина x/]
    B --> C[Задать S = 390]
    C --> D[Вычислить C1 = S / 15 * x]
    D --> E[Вычислить C2 = S / 36 * x]
    E --> F[Вычислить E = C1 - C2]
    F --> G[/Вывести C1, C2 и E/]
    G --> H([Конец])
```

## Формулы

-   Стоимость поездки на Rolls-Royce: `C1 = (390 / 15) * x = 26x`.
-   Стоимость поездки на Ford Escort: `C2 = (390 / 36) * x ≈ 10.8333x`.
-   Экономия при выборе Ford Escort: `E = C1 - C2 ≈ 15.1667x`.

## Результаты работы программы

Если один галлон бензина стоит `2` фунта:

-   Rolls-Royce: `26 × 2 = 52.00` фунта.
-   Ford Escort: `(390 / 36) × 2 ≈ 21.67` фунта.
-   Экономия: `52.00 − 21.67 ≈ 30.33` фунта.

## Ответ

Стоимость поездки на Rolls-Royce составляет `26x` фунтов. При поездке на
Ford Escort можно сэкономить примерно `15.1667x` фунтов.
